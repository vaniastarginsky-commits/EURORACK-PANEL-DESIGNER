Что делаем с styles.css?

Удалили 1984 строк с !important из 4905 — осталось 2921. Приложение сломано. Три пути дальше:

A

Полный переписать с нуля

Выбросить текущий styles.css. Написать чистый CSS с нуля — по доменам: переменные, reset, layout, компоненты, мобайл. Никаких v422/v448 блоков. ~800–1200 строк без !important.

Плюсы

  • Идеальная архитектура
  • Никакого legacy мусора
  • Легко поддерживать

Минусы

  • Высокий риск — можно пропустить edge-cases
  • Долго (неделя+)
  • 21 screenshot-тест нужно пересмотреть
B

Восстановить + вычистить !important

Вернуть бэкап. Систематически убирать !important — переписывать правила с правильной специфичностью вместо патча. Постепенно, поверхность за поверхностью.

Плюсы

  • Меньший риск — работаем с проверенной базой
  • Можно проверять каждый шаг
  • Тесты продолжают работать

Минусы

  • Всё равно много работы
  • Patch-блоки v422..v508 останутся
  • Архитектура так и не улучшится
C

Гибрид: взять stripped + дописать без !important

Оставить текущие 2921 строк. Добавить обратно нужные свойства из удалённых строк — но уже без !important, с правильной специфичностью. Реорганизовать по доменам.

Плюсы

  • Уже убрали 1984 строк-мусора
  • Каждое добавление — осознанный выбор
  • Хорошая база для чистой архитектуры

Минусы

  • Нужно вручную разобрать 1984 удалённых строк
  • Некоторые дубли всё ещё в файле
  • Риск пропустить что-то важное
