> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Extract `COMPONENT_LIBRARY` data and React app state infrastructure from core.js's 70KB minified line into `componentLibrary.js` and `appState.js`.

**Architecture:** Global scripts, no bundler. Extraction uses a Node.js character-offset script since target code is on a single 70KB minified line (awk line-range extraction doesn't apply). One wave per commit, verified via npm run screenshot after each.

**Tech Stack:** Vanilla JS, React 18 UMD, Node.js (for extraction scripts), Python http.server, Playwright.

## Task 1 — Wave 5: Extract `src/componentLibrary.js`

**Files:**
- Create: `src/componentLibrary.js`
- Modify: `src/core.js`
- Modify: `index.html`

### Background

`core.js` line 2 is a single ~70KB minified line. `COMPONENT_LIBRARY` is a large `const COMPONENT_LIBRARY=[...]` array embedded in that line. It's pure data — objects with numeric/string fields, no function calls. It starts at `const COMPONENT_LIBRARY=[` and ends at the matching `]` before the next `const` or `function`.

The extraction cannot use awk line ranges. Instead, use a Node.js script to find the token, count brackets, and split.

- [ ] **Step 1: Confirm COMPONENT_LIBRARY is in core.js line 2**

```bash
grep -o "const COMPONENT_LIBRARY=\[" src/core.js
```

Expected: prints `const COMPONENT_LIBRARY=[`

- [ ] **Step 2: Write extraction script**

Create `/tmp/extract_library.js`:

```js
const fs = require('fs');
const src = fs.readFileSync('src/core.js', 'utf8');

// Find COMPONENT_LIBRARY start
const token = 'const COMPONENT_LIBRARY=[';
const start = src.indexOf(token);
if (start === -1) { console.error('COMPONENT_LIBRARY not found'); process.exit(1); }

// Find matching closing bracket by counting nesting (skip brackets inside strings)
let depth = 0;
let inString = false;
let stringChar = '';
let end = -1;
for (let i = start + token.length - 1; i < src.length; i++) {
  const ch = src[i];
  if (inString) {
    if (ch === stringChar && src[i-1] !== '\\') inString = false;
    continue;
  }
  if (ch === '"' || ch === "'" || ch === '`') { inString = true; stringChar = ch; continue; }
  if (ch === '[' || ch === '{') { depth++; continue; }
  if (ch === ']' || ch === '}') {
    depth--;
    if (depth === 0) { end = i; break; }
  }
}
if (end === -1) { console.error('Could not find end of COMPONENT_LIBRARY'); process.exit(1); }

// The full declaration including trailing semicolon if present
let declEnd = end + 1;
if (src[declEnd] === ';') declEnd++;

const libCode = src.slice(start, declEnd);
const coreWithout = src.slice(0, start) + src.slice(declEnd);

fs.writeFileSync('src/componentLibrary.js', `// Component library data — all built-in component definitions.\n// No dependencies.\n${libCode}\n`);
fs.writeFileSync('src/core.js', coreWithout);

console.log('Extracted', libCode.length, 'chars to src/componentLibrary.js');
console.log('core.js reduced by', libCode.length, 'chars');
```

## Task 2 — Wave 6: Extract `src/appState.js`

**Files:**
- Create: `src/appState.js`
- Modify: `src/core.js`
- Modify: `index.html`

### Background

After wave 5, core.js line 2 still contains the React app state infrastructure: `AppStateContext`, `AppDispatchContext`, `appReducer`, `AppProvider`, `useAppState`, `useAppDispatch`. These depend only on React globals (already loaded via CDN) and the constants in core.js. They must load after core.js (for constants) but before anything that calls `useAppState` or `useAppDispatch` (canvasOverlays.js, App.js).

Use the same character-offset approach to extract each token.

- [ ] **Step 1: Confirm all 6 symbols are in core.js**

```bash
grep -o "const AppStateContext=\|const AppDispatchContext=\|function appReducer\|function AppProvider\|const useAppState=\|const useAppDispatch=" src/core.js
```

Expected: all 6 patterns printed.

- [ ] **Step 2: Write extraction script**

Create `/tmp/extract_appstate.js`:

```js
const fs = require('fs');
let src = fs.readFileSync('src/core.js', 'utf8');

// Helper: extract a token starting at a search string, returns {code, newSrc}
function extractToken(src, startToken, endWith) {
  const start = src.indexOf(startToken);
  if (start === -1) return null;
  
  // For const declarations ending with ; find the semicolon after the value
  // For function declarations find the matching }
  let depth = 0;
  let inString = false;
  let stringChar = '';
  let i = start;
  let foundBody = false;
  
  for (; i < src.length; i++) {
    const ch = src[i];
    if (inString) {
      if (ch === stringChar && src[i-1] !== '\\') inString = false;
      continue;
    }
    if (ch === '"' || ch === "'" || ch === '`') { inString = true; stringChar = ch; continue; }
    if (ch === '{' || ch === '[' || ch === '(') { depth++; foundBody = true; continue; }
    if (ch === '}' || ch === ']' || ch === ')') {
      depth--;
      if (foundBody && depth === 0) {
        i++;
        if (src[i] === ';') i++;
        break;
      }
    }
    // For simple const X=value; without nested braces/brackets
    if (!foundBody && ch === ';') { i++; break; }
  }
  
  return { code: src.slice(start, i), newSrc: src.slice(0, start) + src.slice(i) };
}

const extracts = [];
const tokens = [
  'const AppStateContext=',
  'const AppDispatchContext=',
  'function appReducer(',
  'function AppProvider(',
  'const useAppState=',
  'const useAppDispatch=',
];

for (const token of tokens) {
  const result = extractToken(src, token);
  if (!result) { console.error('Not found:', token); process.exit(1); }
  extracts.push(result.code);
  src = result.newSrc;
  console.log('Extracted:', token, '→', result.code.length, 'chars');
}

const appStateCode = extracts.join('\n');
fs.writeFileSync('src/appState.js',
  `// React app state: context, reducer, AppProvider, useAppState, useAppDispatch.\n// Depends on: React globals (useState, useReducer, useContext, createContext) from CDN.\n// Load after core.js (uses HP_TO_MM, PANEL_HEIGHT_MM, and other core constants).\n${appStateCode}\n`
);
fs.writeFileSync('src/core.js', src);
console.log('\nWrote src/appState.js');
console.log('core.js size now:', src.length, 'chars');
```

## Verification summary

After both waves:

```bash
wc -c src/core.js src/componentLibrary.js src/appState.js
```

`COMPONENT_LIBRARY` is typically 10–25KB of data. `appState.js` (reducer + context) is typically 5–10KB. `core.js` should shrink accordingly.

```bash
# No definition duplicates:
for sym in COMPONENT_LIBRARY appReducer AppStateContext useAppState; do
  echo -n "$sym: "
  grep -rl "const $sym=\|function $sym\b" src/core.js src/componentLibrary.js src/appState.js 2>/dev/null | tr '\n' ' '
  echo
done
```

Each symbol should appear in exactly one file.
