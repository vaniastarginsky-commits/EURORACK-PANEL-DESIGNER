# Design review targets

## Desktop workspace
Expected:
- No black holes when sidebars are hidden.
- Canvas expands when left/right panels are closed.
- Topbar does not wrap.
- Mobile bottom dock is not visible on desktop.

Check screenshots:
- desktop-empty-1440.png
- desktop-left-hidden-1440.png
- desktop-right-hidden-1440.png
- desktop-both-hidden-1440.png

## Mobile workspace
Expected:
- Exactly one bottom dock.
- HUD does not cover the panel.
- Left/right drawers open correctly.
- No random status/debug text over canvas.

Check screenshots:
- mobile-empty-390.png
- mobile-left-open-390.png
- mobile-right-open-390.png

## Templates
Expected:
- Desktop: cards in 2–3 columns.
- Cards show preview, title, metadata, actions.
- Confirm dialog opens centered.

Expected:
- Header / preview / tabs / content layout.

- No clipped checkbox labels.
