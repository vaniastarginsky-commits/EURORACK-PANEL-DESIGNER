# Visual Review Notes

Use `design-review/current` for the reference set, `design-review/after` for fresh captures, and `design-review/approved` for reviewed screenshots that can become the next baseline.

Run:

```sh
npm run dev
npm run screenshot
```

Set `BASE_URL` or `DESIGN_REVIEW_OUT` when capturing a different server or output directory.

Canvas-specific checks: whenever canvas behavior or layout changes, place any component on the panel and drag it to confirm component movement still works.
